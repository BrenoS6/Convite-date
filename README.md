💌 Convite para um Date

Um convite especial, interativo e romântico para transformar um simples encontro em um momento inesquecível. ❤️

Este projeto é um site de convite para um date, desenvolvido para permitir que a pessoa convidada escolha como e quando deseja viver esse momento especial.

 ✨ Funcionalidades

- 📍 **Escolha de local:** opções de lugares para o encontro.
- 📅 **Seleção de data:** escolha do melhor dia para o date.
- 🕒 **Escolha de horário:** definição do horário do encontro.
- 💬 **Confirmação pelo WhatsApp:** envio dos detalhes do convite diretamente pelo WhatsApp.
- 📆 **Integração com Google Agenda:** criação de um compromisso com a data, o horário e as informações do encontro.
- 💖 **Experiência interativa:** uma forma criativa e especial de convidar alguém para sair.

🎯 Objetivo do projeto

Criar uma experiência digital simples, intuitiva e romântica, tornando o convite para um encontro mais pessoal e permitindo que os detalhes sejam definidos de maneira prática.

 🛠️ Tecnologias

- HTML5 — estrutura da página.
- CSS3 — estilização e identidade visual.
- JavaScript — interações, seleção de data e horário e geração dos links para compartilhamento e agenda.

🚀 Como utilizar

1. Acesse o site do convite.
2. Escolha o local onde deseja que o encontro aconteça.
3. Selecione a data e o horário.
4. Confira os detalhes do convite.
5. Envie o convite pelo WhatsApp ou adicione o compromisso ao Google Agenda.

 🔗 Integrações

**WhatsApp:** permite preparar uma mensagem com os detalhes escolhidos para facilitar a confirmação do encontro.

**Google Agenda:** permite abrir o formulário de criação de um evento com as informações do date preenchidas.

> Observação: o envio pelo WhatsApp depende da confirmação do usuário no aplicativo, e o evento do Google Agenda precisa ser salvo pelo usuário.

 💡 Conceito

Mais do que um convite, este projeto é uma maneira criativa de demonstrar interesse, planejar um momento especial e deixar a escolha do encontro nas mãos de quem recebe o convite.

*Porque alguns momentos merecem um convite diferente.* 💗
